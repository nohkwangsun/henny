헨니 체크 설치

폰에서 이 페이지를 열고 아래 버튼을 누르세요.

APK 받기 항상 최신 버전을 받습니다 이미 설치했어요 — 앱 열기
“파일이 기기에 위험을 줄 수 있습니다”가 뜨면 정상입니다. 스토어를 거치지 않은 앱은 크롬이 모두 이렇게 경고합니다. 계속 또는 어쨌든 다운로드를 누르세요.

처음 설치할 때만 — 한 번 허용

  1. 받은 파일을 누르면 “이 출처의 앱 설치 차단됨”이 뜹니다.
  2. 설정을 누르면 바로 해당 화면으로 갑니다.
  3. 이 출처 허용을 켜고 뒤로 나옵니다.
  4. 설치를 누릅니다.

이 허용은 방금 사용한 앱(크롬 등) 하나에만 붙습니다. 설치가 끝나면 같은 화면에서 다시 꺼 두셔도 됩니다.

업데이트할 때

같은 버튼을 다시 누르고 설치하면 됩니다. 지우지 마세요. 덮어 설치하면 기록이 그대로 남습니다.

APK를 다시 받아야 하는 경우는 드뭅니다

화면과 규칙은 웹에 있어서, 대부분의 변경은 앱을 다시 열기만 하면 반영됩니다. 알림 방식이나 권한처럼 앱 껍데기 자체가 바뀔 때만 다시 받으면 됩니다.

설치가 안 될 때

“앱이 설치되지 않았습니다”가 뜹니다

예전에 다른 키로 서명된 시험용 APK가 깔려 있으면 덮어 설치가 거부됩니다. 이때만 기존 앱을 지우고 다시 설치하세요. 지우기 전에 앱의 설정 → 관리자 코드(또는 연결 코드)를 복사해 두면 그대로 복구됩니다.

알림이 안 옵니다

앱의 설정 → 알림에서 권한과 알람 권한을 켜 주세요. 삼성 갤럭시는 설정 → 앱 → 헨니 체크 → 배터리 → 제한 없음도 함께 해야 절전이 알람을 건너뛰지 않습니다.
