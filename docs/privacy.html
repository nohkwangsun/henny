헨니 체크 개인정보처리방침

최종 수정일: 2026년 8월 19일 · 앱 패키지: com.henny.checklist

요약. 헨니 체크는 서버를 운영하지 않습니다. 개발자는 이용자의 어떤 자료도 받지 않고 볼 수도 없습니다. 광고, 분석 도구, 외부 SDK가 하나도 들어 있지 않습니다. 자료는 기본적으로 기기 안에만 저장되며, 부모가 직접 가족 저장소를 설정한 경우에만 부모가 고른 그 저장소로 전송됩니다.

1. 수집하는 정보

항목내용어디에 저장되나
아이 이름 또는 별명 부모가 직접 입력합니다. 실명을 넣지 않아도 앱은 정상 동작하며, 앱은 별명 사용을 권장합니다. 기기 + (설정 시) 가족 저장소
할 일·미션·알림 설정 부모가 입력한 할 일 제목, 요일, 마감 시각, 알림 시각. 기기 + (설정 시) 가족 저장소
체크 기록 날짜별로 어떤 할 일을 완료했는지와 완료한 시각. 기기 + (설정 시) 가족 저장소
저장소 접속 설정 이용자가 입력한 저장소 주소와 API 키. 기기에만 저장되며 전송되지 않습니다. 기기에만

수집하지 않는 것: 계정·로그인 정보, 이메일, 전화번호, 주소록, 위치, 사진, 카메라·마이크 자료, 광고 식별자(AAID), 기기 식별자, 사용 통계, 크래시 분석 자료. 앱에는 광고 SDK·분석 SDK·추적 도구가 전혀 없습니다.

2. 정보를 사용하는 목적

오직 앱 기능 제공을 위해서만 사용합니다. 오늘 할 일 목록을 보여주고, 정해진 시각에 알림을 띄우고, 주·월 달성률을 계산하고, 부모 기기와 아이 기기 사이에서 같은 내용을 보이게 하는 용도입니다. 광고, 마케팅, 프로파일링, 판매에 사용하지 않습니다.

3. 정보가 전송되는 곳

앱 설정에서 가족 저장소를 고르지 않으면(기본값 “안 씀”) 자료는 기기 밖으로 전혀 나가지 않습니다.

부모가 가족 저장소를 설정하면, 위 1번 표의 자료가 부모가 직접 고른 저장 서비스로만 HTTPS로 전송됩니다. 선택지는 다음과 같습니다.

  • 구글 Firebase 실시간 데이터베이스 — 이용자 본인의 구글 계정으로 만든 프로젝트. 구글의 Firebase 개인정보 및 보안 정책이 적용됩니다.
  • JSONBin.io — 이용자 본인의 무료 계정. 해당 서비스의 개인정보처리방침이 적용됩니다.
  • 이용자가 직접 입력한 JSON 주소 — jsonblob.com, npoint.io 등 이용자가 고른 곳. 해당 서비스의 방침이 적용됩니다.

이 저장 서비스는 이용자가 선택하고 이용자의 계정으로 운영하는 보관소입니다. 개발자는 이 저장소에 접근할 수 없고, 어떤 자료도 전달받지 않습니다. 개발자가 제3자에게 자료를 판매하거나 공유하는 일은 없습니다.

4. 아동의 개인정보

이 앱은 가족이 함께 쓰도록 만들어졌고 아동이 직접 사용합니다. 설정은 보호자가 하며, 아이 기기는 보호자가 발급한 연결 코드를 입력해야 연결됩니다.

  • 아동에게 개인정보 입력을 요구하지 않습니다. 아이 기기에서 아이가 하는 일은 체크뿐입니다.
  • 이름은 보호자가 입력하며 별명 사용을 권장합니다.
  • 아동을 대상으로 한 광고를 보여주지 않으며, 광고 SDK가 없습니다.
  • 아동의 자료로 프로파일링하거나 제3자에게 제공하지 않습니다.
  • 위치·연락처·사진·마이크 권한을 요청하지 않습니다.

보호자는 언제든 앱 설정의 모든 데이터 지우기로 아동의 자료를 삭제할 수 있습니다(6번 참고).

5. 보관 기간

날짜별 상세 기록은 약 150일간 보관하고, 그보다 오래된 것은 월별 합계(완료 수 / 전체 수)로만 남기고 상세 내용은 지웁니다. 이 정리는 기기와 가족 저장소 양쪽에 동일하게 적용됩니다.

6. 삭제 방법

  • 앱 안에서: 설정 → 모든 데이터 지우기. 이 폰의 기록과 가족 저장소의 문서를 함께 비웁니다.
  • 기기에서만: 앱을 삭제하면 그 기기의 자료가 모두 사라집니다.
  • 저장 서비스에서: 이용자 본인의 Firebase 콘솔이나 JSONBin 계정에서 해당 자료를 직접 삭제할 수 있습니다.

개발자는 어떤 자료도 보관하고 있지 않으므로, 개발자에게 삭제를 요청할 대상 자료가 없습니다.

7. 권한

8. 보안

전송은 모두 HTTPS로 이루어집니다. 다만 이용자가 인증 없는 저장 주소(예: jsonblob.com)를 선택하면 주소를 아는 사람은 누구나 그 문서를 읽고 쓸 수 있습니다. 앱은 설정 화면에서 이 점을 안내합니다. 저장소 API 키는 기기에만 보관되며 개발자에게 전송되지 않습니다.

9. 변경 안내

이 방침이 바뀌면 이 페이지의 최종 수정일이 갱신됩니다. 중요한 변경은 앱 업데이트 설명에도 적습니다.

Privacy Policy (English)

Last updated: 19 August 2026 · Package: com.henny.checklist

Summary. Henny Check runs no server. The developer receives no user data and cannot access any. The app contains no ads, no analytics, and no third-party SDKs. Data stays on the device by default and is transmitted only to a storage service the parent explicitly configures.

Data handled

A child's name or nickname (entered by the parent), the chore titles / schedules / reminder times the parent sets, and per-day completion records with timestamps. Storage credentials the user enters are kept on the device only and are never transmitted.

The app does not collect accounts, email, phone numbers, contacts, location, photos, advertising identifiers, device identifiers, usage analytics, or crash analytics.

Purpose

App functionality only: showing today's list, firing reminders, computing weekly and monthly completion rates, and keeping a parent device and a child device in sync. No advertising, no profiling, no sale of data.

Transmission

With the default setting (“no sync”), nothing leaves the device. If the parent configures a family store, the data above is sent over HTTPS only to the service the parent chose — their own Google Firebase Realtime Database project, their own JSONBin.io account, or a JSON URL they supply. Those services are operated under the user's own account and are governed by their own privacy policies. The developer has no access to them and receives nothing.

Children

The app is intended for family use and is used by children. Setup is performed by a parent, and a child device connects only with a pairing code issued by the parent. Children are never asked to enter personal information; a child only taps items to check them off. Nicknames are recommended instead of real names. There are no ads, no ad SDKs, no profiling, and no requests for location, contacts, photos, or microphone access.

Retention and deletion

Detailed per-day records are kept for about 150 days; older entries are collapsed into monthly totals and the details are discarded, on the device and in the family store alike. A parent can erase everything at any time via Settings → Delete all data, which clears this device and empties the documents in the family store. Uninstalling removes all local data. The developer holds no data, so there is nothing for a user to request deletion of from the developer.

Security

All transfers use HTTPS. Note that if the user picks an unauthenticated storage URL (for example jsonblob.com), anyone who knows that URL can read and write that document; the app states this in its settings screen.
