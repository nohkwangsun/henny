# 자료가 사라졌을 때

## 앱을 업데이트했더니 화면이 비었습니다

**Compose 앱 → WebView 앱으로 바뀌던 그 한 번만 생기는 일입니다.**

예전 앱은 자료를 파일에, 지금 앱은 WebView 안에 저장합니다. 자리가 달라서
새 앱이 예전 자료를 못 봤습니다.

**지금은 앱이 알아서 옮겨 옵니다.** 최신 APK 로 덮어 설치하고 앱을 열면
"예전 앱에 있던 자료를 그대로 가져왔습니다" 라고 뜹니다.

단, **앱을 지웠다 깐 경우에는 파일도 함께 지워져서** 이 방법이 안 됩니다.
아래 복구 방법으로 가세요.

---

## 복구하기

### 저장할 곳(Firebase)을 쓰고 있었다면

자료는 클라우드에 그대로 있습니다.

1. 앱 실행 → **코드를 받았어요**
2. 저장해 둔 **관리자 코드**(관리자) 또는 **연결 코드**(작업자)를 붙여넣기
3. 자동으로 내려받습니다

### 코드를 저장해 두지 않았다면

Firebase 콘솔에서 직접 찾을 수 있습니다.

1. <https://console.firebase.google.com> → 프로젝트 → Realtime Database → **데이터** 탭
2. `henny` 아래에 무작위 문자열로 된 항목이 보입니다. 그게 팀 키입니다
3. 그 아래 `plan` 을 펼치면 작업자 이름이 보여 우리 팀인지 확인할 수 있습니다

관리자 기기를 새로 설정할 때 **같은 주소를 넣어도 앱이 새 팀 키를 만듭니다.**
그러면 예전 자료에 닿지 못합니다. 이 경우는 코드가 없으면 되살리기 어려우니,
**관리자 코드를 지금 저장해 두세요.**

> 관리자 → 설정 탭 → **관리자 코드 보기** → 복사 → 메모나 비밀번호 관리자에 보관

### 저장할 곳 없이 그 기기에만 쓰고 있었다면

앱을 지웠다면 되살릴 방법이 없습니다.
**지금이라도 저장할 곳을 연결해 두세요** ([SETUP.md](SETUP.md)).
기기가 비어도 자료는 남습니다.

## 업데이트할 때마다 지웠다 깔아야 합니다

**서명이 달라서 그렇습니다.** 안드로이드는 서명이 다른 앱을 같은 앱으로 보지 않아
덮어 설치를 거부합니다.

GitHub Secrets 에 업로드 키를 넣기 전에는 CI 가 **일회용 키**로 서명했습니다.
빌드마다 서명이 달랐던 것입니다.

**키를 등록한 지금은 해결됐습니다.** 모든 빌드가 같은 키로 서명되므로
덮어 설치가 되고 자료가 유지됩니다.

설정 화면 아래에 **앱 버전과 웹 버전**이 표시되니, 업데이트가 실제로 반영됐는지
눈으로 확인할 수 있습니다.

---

## 화면 위쪽 글씨가 시계와 겹칩니다

앱이 상태바 뒤까지 그려서 생긴 문제였습니다. 고쳤습니다.
**최신 APK 로 덮어 설치**하면 없어집니다.

---

## "이전 저장 형식을 읽지 못해 새로 시작했습니다"

개발 중에 저장 형식이 바뀌면 예전 파일을 못 읽습니다.
이때 조용히 버리지 않고 원본을 `.broken` 으로 남겨 둡니다.

저장할 곳을 쓰고 있으면 **잠시 뒤 원격에서 다시 내려받습니다.**
내려받은 게 맞다면 설정 화면에서 **알림 지우기** 를 누르면 됩니다.

## 매번 파일을 받아 설치하는 게 번거롭습니다

**앱은 한 번만 설치하면 됩니다.** 화면과 기능은 웹에 있어서 고치면 앱을 여는 순간
최신이 됩니다. 껍데기(`app/`)를 건드렸을 때만 다시 설치하면 되는데, 그런 일은 드뭅니다.

껍데기 업데이트까지 자동으로 하려면 Play 내부 테스트에 올리면 됩니다.
업로드 키는 이미 준비돼 있으니 [PLAY_STORE.md](../PLAY_STORE.md) 2단계부터 진행하면 됩니다.
