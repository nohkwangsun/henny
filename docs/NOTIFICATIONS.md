# 알림

작업자가 앱을 아예 안 여는 것이 가장 큰 문제라, 알림을 세 종류로 나눴습니다.

## 종류

**1. 하루 점검 알림** — 관리자가 시각을 정합니다. 기본값:

| 시각 | 문구 | 조건 |
|---|---|---|
| 아침 7:30 | 오늘 할 일을 확인해요 | 남은 게 없어도 울림 |
| 오후 4:00 | 지금 하나만 시작해볼까? | 남은 게 있을 때만 |
| 저녁 8:00 | 자기 전 마지막 점검! | 남은 게 있을 때만 |

알림을 펼치면 남은 작업 목록과 배점이 그대로 나옵니다.
"확인해라"로 끝나지 않고 무엇을 해야 하는지 알림에서 바로 보입니다.

**2. 마감 알림** — 작업에 마감 시각을 넣으면 기본 1시간 전에 울립니다
(30분 / 1시간 / 2시간 중에 고를 수 있습니다).

**3. 관리자 요약** — 저녁 8:30 에 "김민준 4/5 · 야간조 3/3" 형태로 하루 결과를
관리자 기기에 한 번 보냅니다.

## 어떻게 도는가

웹앱이 **3일치 알람 일정**을 미리 계산해 네이티브 껍데기에 넘깁니다.
껍데기는 그중 **다음에 울릴 하나**만 예약해 두고, 울릴 때마다 그다음을 다시 예약합니다.

- 앱을 안 열어도 정기 알림은 그대로 울립니다
- 재부팅·앱 업데이트·시간대 변경 뒤에도 자동으로 다시 걸립니다
- 서버가 필요 없습니다. 인터넷이 끊겨도 정해진 시각에 울립니다

브라우저는 **정해진 시각에 스스로 울리는 것**을 못 합니다.
(푸시 알림은 되지만 서버가 밀어 줘야 하고, 기기가 스스로 시각을 예약하는 API 는
표준화되지 못했습니다.) 그래서 알림만 네이티브로 남겼습니다.

## 안 울릴 때

### 앱 안에서 먼저

- 설정 탭 → **알림 켜기** 로 권한 확인
- 설정 탭 → **알람 권한 열기** 에서 '알람 및 리마인더' 허용 (안드로이드 12 이상)

### 삼성 갤럭시는 여기까지로 부족합니다

One UI 의 절전 기능이 오래 안 쓴 앱을 잠재워 알람을 통째로 건너뜁니다.
작업자 기기는 하루에 몇 번만 앱을 열기 때문에 바로 이 '안 쓰는 앱' 취급을 받습니다.

1. **이 앱을 절전에서 제외**
   설정 → 앱 → **헨니 체크** → 배터리 → **제한 없음**
2. **미사용 앱 절전 끄기**
   설정 → 배터리 → 백그라운드 사용 제한 → **미사용 앱을 절전 상태로 전환** 끄기

> One UI 버전에 따라 메뉴 이름이 조금씩 다릅니다.
> "디바이스 케어 → 배터리 → 앱 절전 관리 → 절전 제외 앱" 에 있는 기종도 있습니다.
> 어느 쪽이든 **헨니 체크가 '제한 없음' 또는 '절전 제외'** 로 되어 있으면 됩니다.

### 샤오미

설정 → 앱 → 앱 관리 → 헨니 체크 → 배터리 절약 → **제한 없음**,
그리고 **자동 시작(자동 실행)** 허용까지 켜야 합니다.
